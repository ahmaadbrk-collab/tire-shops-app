# نظام متابعة محلات الإطارات - دليل التشغيل السحابي

## ملخص هذا التحديث
- **أرقام أرشفة تلقائية** لكل عملية: مبيعات (SAL-FAK-001)، مصروفات (EXP-FAK-001)، عهدة (CUS-FAK-001)، مناقلات (TRF-FAK-001)
- **الموظفين**: صار لازم تحدد الفرع وقت الإضافة
- **عهدة المحصلين**: تحدد الآن من أي صندوق أخذ المحصل المبلغ، وتخصم فعلياً من ذلك الصندوق. فيه زر "رُحّلت / لم تُرحّل" لكل عملية
- **إقفال الصندوق**: زر "مقفل / مفتوح"، والرصيد المتوقع يحسب المصروفات + العهدة + المناقلات تلقائياً
- **تسوية الشبكة**: أُعيد تصميمها بالكامل — الفرق بين مبيعات النظام والإيداع الفعلي يترحّل تراكمياً لليوم اللي بعده، وتظهر حالة "مطابق" أو "مرحّل" بلون مختلف
- **مناقلة بين الصناديق**: قسم جديد كامل (تحويل من صندوق لصندوق، مثلاً نقدي → عهدة)
- **المصروفات**: نوع جديد "فاتورة مشتريات" مع حقلي رقم الفاتورة واسم المورد
- **دفتر الصندوق**: تقرير جديد بشاشة التقارير يعرض كل حركة (بيع، مصروف، عهدة، مناقلة) لصندوق معين بفرع معين، بالترتيب الزمني، مع رصيد متحرك
- قاعدة البيانات: ملف JSON بسيط (data.json) بدون أي تعقيد تثبيت

## خطوات الرفع على GitHub (تحديث الملفات الموجودة)

لكل ملف من: `server.js` و `index.html` (و`package.json` لو ما رفعته قبل):

1. روح لصفحة الريبو حقك على GitHub
2. اضغط على اسم الملف
3. اضغط أيقونة القلم ✏️ (Edit this file)
4. امسح كل المحتوى، والصق المحتوى الجديد من هذا المجلد
5. اضغط "Commit changes"

Render.com يعيد النشر تلقائياً بعد كل Commit (خلال دقيقة أو دقيقتين).

## ملاحظات مهمة

- **data.json** يُنشأ تلقائياً أول تشغيل، ما تحتاج ترفعه.
- خذ نسخة احتياطية أسبوعياً من زر "تنزيل نسخة احتياطية" بتبويب التقارير.
- بيانات الدخول الافتراضية: `ahmad` / `tire2026` (غيّرها من Environment Variables بـ Render: `APP_USER`, `APP_PASS`).
- رموز الفروع المستخدمة بالترقيم: فخامة الاطار = FAK، روائع الافق = RAF، روعة المنار = RMN.
