# نظام متابعة محلات الإطارات - دليل التشغيل السحابي

## الخطوات (مرة وحدة بس)

### ١. سوّي حساب Render.com (مجاني)
اذهب إلى https://render.com واعمل حساب (يحتاج إيميل عادي، مرة وحدة بس).

### ٢. ارفع هذا المشروع على GitHub
- سوّي حساب GitHub (لو ما عندك) وسوّي repository جديد اسمه مثلاً `tire-shops-app`
- ارفع كل ملفات هذا المجلد فيه (server.js, package.json, public/, README.md)

### ٣. اربط Render بمشروع GitHub
- من لوحة Render اضغط "New +" ثم "Web Service"
- اختر الـ repository اللي رفعته
- الإعدادات:
  - **Build Command:** `npm install`
  - **Start Command:** `node server.js`
  - **Instance Type:** Free
- أضف متغيرات البيئة (Environment Variables) من قسم Environment:
  - `APP_USER` = اسم المستخدم اللي تبيه (مثلاً: ahmad)
  - `APP_PASS` = كلمة السر اللي تبيها (غيّرها عن الافتراضية!)
  - `SESSION_SECRET` = أي نص عشوائي طويل (مثلاً: xk29fjaLp93mqZ8v)
- اضغط "Create Web Service"

### ٤. خلاص
بعد دقيقتين تقريباً، Render يعطيك رابط زي:
`https://tire-shops-app.onrender.com`

افتح هذا الرابط من أي جهاز، أي مكان، سجل دخول باسم المستخدم وكلمة السر اللي حطيتها، وابدأ الشغل.

## ملاحظات مهمة

- **قاعدة البيانات (data.sqlite)** تتخزن على نفس السيرفر. في النسخة المجانية من Render، الملفات المؤقتة قد تُمسح أحياناً عند إعادة تشغيل السيرفر (نادراً). لحماية بياناتك، استخدم زر "تنزيل نسخة احتياطية" من تبويب المتابعة بشكل أسبوعي على الأقل.
- لو حبيت حماية أقوى للبيانات لاحقاً (تخزين دائم 100%)، ينصح بترقية للخطة المدفوعة البسيطة من Render (تدعم Persistent Disk)، أو نقل قاعدة البيانات لخدمة قاعدة بيانات مستقلة.
- لتغيير اسم المستخدم أو كلمة السر لاحقاً: عدّل المتغيرات `APP_USER` و `APP_PASS` من إعدادات Render (Environment) واحفظ، السيرفر يعيد التشغيل تلقائياً.
